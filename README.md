### What is Git/Github, and how do I use it with R?

The Open Research LJMU workshop

[**What is Git/Github, and how do I use it with R?**](https://zajitschek.github.io/git_workshop_LJMU_2025/)

was held on 17/09/2025 as part of the LJMU R Community's [**LJMU Bag of tRicks**](https://ljmutricks.github.io/bag-of-tricks).

The workshop gives an introduction to Git, GitHub, GitHub Desktop, and their integration with RStudio.
